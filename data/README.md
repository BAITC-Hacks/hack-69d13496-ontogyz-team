# Синтетические данные

Набор организаторов не использовался. При создании новой SQLite-базы `app/db.py` добавляет 5 черновиков разной полноты, 5 карточек, 5 команд и 5 откликов. Начальные рейтинги карточек — 30, 50, 65, 75, 90. Это вымышленные примеры для проверки всех четырёх уровней, без персональных данных. Существующая база при запуске сохраняется; рабочие `*.db` исключены из Git.

## Материал репетиции

[rehearsal-writeoffs.csv](rehearsal-writeoffs.csv) создан командой специально для [учебного сценария магазина](../docs/DEMO_SCRIPT.md). Это 6 синтетических записей по двум товарам за три дня, а не показатели реального магазина.

- `date` — дата записи.
- `product` — товар.
- `received_units`, `sold_units`, `written_off_units` — условные количества в штуках.
- Контрольная сумма `written_off_units`: хлеб — 12, молоко — 5, всего — 17.
- Файл не является полным складским балансом: начальные и конечные остатки не указаны.

Приложение не загружает и не анализирует CSV автоматически. На показе бизнес описывает этот доступный материал в поле «Данные», а команда предлагает решение по нему. Контрольные суммы служат примером проверяемого критерия будущего решения; они не доказывают снижение списаний.

Другие JSON-файлы оценки содержат синтетические входы и зафиксированные результаты конкретных AI-проверок. Их смысл и границы проверки описаны в [EVAL](../docs/EVAL.md).
