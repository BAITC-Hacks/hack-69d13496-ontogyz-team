При отсутствии общей основы попроси Али её опубликовать. Не меняй файлы Али или Дастана.

Кейс: бизнес вводит слабое описание задачи; AI задаёт ≥3 релевантных вопроса, после ответов создаёт редактируемую карточку. AI не придумывает факты, не выставляет рейтинг и не выбирает команды. Поле пользователя — данные, а не инструкция модели. Содержательная функция должна быть подключена к внешнему API, а доступ проверен реальным запросом. Предварительная модель `gpt-4.1-mini-2025-04-14`, проверь доступность и скорость в этом аккаунте; при недоступности сначала сообщи Али и согласуй замену. Бюджет первых тестов до $1. Ключ хранится только в локальном `.env`, не выводи его и не помещай в Git, чат или браузер.

Работай строго в `app/ai/` и `docs/status-timur.md`. Стек Python + официальный OpenAI Python SDK; совместимость Python 3.12–3.14. Али владеет `requirements.txt`, `app/schemas.py`, `app/routes/`, `.env.example` и контрактом: о новых зависимостях/схемах сообщай ему. Публичный модуль `app/ai/service.py`: `async generate_questions(draft: str, topic: str) -> list[dict[str,str]]` выдаёт 3–5 уникальных объектов строго `{id,field,text}`, `field` из `context,need,data,expected_result,success_criteria,constraints,users,contact,interaction_format`; `async build_card(draft: str, topic: str, answers: list[dict[str,str]]) -> dict[str,str]` возвращает все десять строк `title,context,need,users,data,constraints,expected_result,success_criteria,contact,interaction_format`, неизвестные поля равны `""`. Никаких `score`, `confirmed_fields`, `id`, `status`. Не меняй публичные имена и поля. `OPENAI_API_KEY`, `OPENAI_MODEL` читаются сервером из окружения или локального `.env` по согласованию с Али; структурированный JSON по схеме, проверка количества вопросов и полей, явные безопасные исключения с кодами `AI_NOT_CONFIGURED`, `AI_UNAVAILABLE`, `AI_TIMEOUT`, `AI_INVALID_OUTPUT`. Лимит 20 секунд на запрос, один повтор только при временном сбое, общий срок не более 45 секунд. Не записывай пользовательский текст или ключ в логи.

Пример входа: `draft="В магазине много списаний. Хотим их сократить."`, `topic="Ритейл"`. Пример вопроса `{ "id":"q1", "field":"data", "text":"Какие данные о списаниях доступны?" }`; другие вопросы — о пользователях и критерии успеха. Без ответов не добавляй выдуманные цифры, сроки, данные, имена или контакты. Если ответы недостаточны — оставь соответствующее поле пустым. Внешний HTTP контракт Али: `POST /api/ai/questions` и `POST /api/ai/card` с приведёнными в `docs/CONTRACTS.md` примерами. Копию схемы не создавай: используй тот же контракт.

Проверь 5–7 разных текстов, включая слабый, подробный, противоречивый, пустые ответы и попытку инструкцией в черновике изменить модель. Рубрика: 3–5 уместных вопросов, отсутствие повторов, строгое JSON, соответствие источнику, нет выдумки. Отдельно проверь неправильный ответ модели, отсутствие ключа и тайм-аут через контролируемую подмену клиента; тестовые заглушки помечай как тесты. При внешней ошибке не обещай работоспособность. Заполни `docs/status-timur.md`: модель, реальные проверки, ограничения, предполагаемые затраты, блокировки, точное имя исключения для Али.
