## Воспроизведение

Запустить существующий FastAPI на `127.0.0.1:8001` с отдельным `DATABASE_PATH`.
Используется уже установленный Playwright и Microsoft Edge; зависимости проекта не менялись.
Если Playwright доступен через внешний каталог пакетов, задать соответствующий `NODE_PATH`.

- `node web/tests/check.cjs` — прежние 15 и четыре новые изолированные проверки; клавиатура на двух ширинах.
- `node web/tests/flow.cjs` — создаёт две тестовые задачи и четыре отклика **в проверочной базе**, выполняет PUT, публикацию, ручной выбор и подтверждение этапов, сохраняет снимки.
- `node web/tests/capture.cjs after` — снимки основных экранов на настоящем API с начальными примерами.

Не запускать `capture.cjs before` поверх сохранённого эталона: этот набор зафиксирован до правок.
